## 🔥 Featured Projects

### 🤖 [ResumeIQ](https://github.com/shinde-abhay/ResumeIQ)
AI-assisted resume optimization tool with a **FastAPI backend and static frontend**. It extracts job-description keywords, matches them against a resume, generates targeted suggestions, and re-scores the resume after selected changes.

**Tech:** Python · FastAPI · Groq · PDF/DOCX processing · HTML/CSS/JS

### 📄 [Document ChatBot](https://github.com/shinde-abhay/Document_ChatBot)
Full-stack **RAG chatbot** that lets users upload documents and ask questions about their content. Uses per-user FAISS indexes, conversational context, persistent PostgreSQL chat history, and Gemini for responses.

**Tech:** Python · FastAPI · Streamlit · LangChain · Gemini · FAISS · PostgreSQL

### 🧠 [AI Resume Analyzer](https://github.com/shinde-abhay/AI_Resume_Analyzer)
Resume analysis application that combines **sentence-transformer embeddings, cosine similarity, and an LLM** to evaluate resumes against job descriptions and identify skill gaps and improvements.

**Tech:** Python · Streamlit · Sentence Transformers · Scikit-learn · Hugging Face

### 🎬 [Movie Recommender](https://github.com/shinde-abhay/Movie_Recommender)
Content-based recommendation system using **Sentence-BERT embeddings and cosine similarity** to find semantically similar movies from the TMDB dataset.

**Tech:** Python · NLP · Sentence-BERT · NumPy · Pandas · Streamlit

### 📊 [HR Analytics Dashboard](https://github.com/shinde-abhay/HR-Analytics-Dashboard)
Interactive HR analytics dashboard focused on exploring workforce metrics and business insights through data visualization.

**Tech:** Power BI · Data Analytics · Data Visualization

### 🚗 [Road Accident Analysis](https://github.com/shinde-abhay/Road-Accident-Analysis-Using-Power-BI)
Power BI dashboard for analyzing road-accident data and presenting trends and patterns through interactive visualizations.

**Tech:** Power BI · Data Analytics
